## 🧠 이 스케줄의 핵심 원리: 능동적 인출 (Active Recall)

> **"기억은 꺼낼 때 강해진다."**  
> — 에빙하우스 망각곡선이 말하는 것은 단순히 "복습하라"가 아니라, **어떻게 복습하느냐**가 결정적이라는 것이다.

### 능동적 인출이란?

교재를 **다시 읽는 것(수동적 복습)**이 아니라, 책을 덮고 **기억 속에서 직접 꺼내보는 행위**이다.

| | 수동적 복습 ❌ | 능동적 인출 ✅ |
|:--|:-------------|:-------------|
| **행동** | 단권화 노트를 처음부터 다시 읽기 | 백지에 목차와 핵심 키워드를 기억나는 대로 써보기 |
| **뇌 작동** | "아, 맞다" (인식 = Recognition) | "뭐였더라…" (인출 = Retrieval) |
| **효과** | 친숙함의 착각 → 시험장에서 안 떠오름 | 인출 경로 강화 → 시험장에서 자동 현출 |

### 왜 관세사 시험에 결정적인가?

관세사 2차는 **80분 안에 A4 16면을 써내는 극한 환경**이다.  
조문 번호·핵심 키워드·논리 구조가 **자동으로 현출(現出)**되지 않으면 시간 내 완성이 불가능하다.

- 📌 **읽어서 아는 것 ≠ 써서 표현할 수 있는 것** — 이 간극이 과락의 원인
- 📌 인출에 **실패하더라도** 다시 확인하면 오히려 더 강하게 기억됨 (실패 기반 학습)
- 📌 복습 시간의 **최소 50%**를 인출 활동에 할애해야 효과 발생

### 이 스케줄에서의 적용

| 학습 단계 | 능동적 인출 방법 |
|:---------|:----------------|
| **매일 저녁 (5분)** | 오늘 배운 내용에서 핵심 키워드 3개를 보지 않고 떠올리기 |
| **+1일 복습 (10분)** | 백지에 어제 학습한 챕터의 목차 구조를 기억나는 대로 써보기 |
| **+7일 복습 (20분)** | NotebookLM 챗봇에 "OO에 대해 설명해봐"라고 질문받고 답해보기 |
| **+14일 복습 (15분)** | 해당 주제의 전체 흐름을 백지에 인출 → 빠진 부분만 확인 |
| **기출 답안 작성** | 가장 강력한 인출 — 조문·키워드·논리를 시간 내에 써내는 실전 훈련 |
| **두문자 암기** | `수용생권사`, `처조사특` → 두문자에서 전체 내용을 역으로 인출 |

> ⚡ **핵심 공식**: `읽는 시간 < 떠올리는 시간` — 이 원칙이 35일 전체를 관통한다.
