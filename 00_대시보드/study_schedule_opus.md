## 🔑 절대암기 두문자 & 숫자

### 관세평가
- **가산요소 5가지**: `수용생권사` (수수료·중개료 / 용기·포장 / 생산지원 / 권리사용료 / 사후귀속이익)
- **배제사유 4가지**: `처조사특` (처분·사용제한 / 조건·사정 / 사후귀속이익 미확정 / 특수관계 가격영향)
- **특수관계 7유형**: 임원 / 동업자 / 고용 / 5%주주 / 지배 / 타인지배 / 동일인지배
- **핵심 조문**: 관세법 §30①(가산5종), §30③(배제4종), §30⑤(특수관계), 시행령 §19③⑤(권리사용료), §23①(특수관계)

### 무역실무
- **서류심사**: `5 banking days` (business days 아님!)
- **CIP → ICC(A)** / **CIF → ICC(C)** (뒤바꾸면 치명적 감점)
- **FOB 위험이전**: 본선 선상 적재 (난간 통과 ✕)
- **몬트리올 이의제기**: 수하물 7일 / 화물 14일 / 지연 21일
- **CISG 빈출 조문**: 제14·18·19·21·25·39·46·74조

## ⚡ 핵심 원칙 요약

1. **읽는 시간 < 떠올리는 시간** — 복습 시간의 50% 이상을 능동적 인출에 할애
2. **제1방법에 학습시간 60% 집중** — 관세평가 배점 78.5%가 여기서 나옴
3. **3대 국제규범 정확 암기** — 무역실무 합격의 뿌리 (CISG·Incoterms·UCP 600)
