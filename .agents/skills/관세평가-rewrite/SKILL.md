# 관세평가 단권화 본문 재작성

## 사용법

```
/관세평가-rewrite <md_파일_경로>
```

예시: `/관세평가-rewrite 01_관세평가/10_단권화/03_04_공제요소.md`

---

## 실행 지시문

아래 5단계를 **사용자 확인 없이 자동으로** 순서대로 실행한다.
각 단계 시작 시 진행 상황을 한 줄로 출력한다.

---

## STEP 1 — 파일 읽기 + 단원이름 추출

1. 인수로 받은 `<md_파일_경로>` 파일을 Read 도구로 읽는다.
2. **단원이름 추출 규칙**:
   - 파일명에서 숫자+언더스코어 prefix를 제거한다.
     - 예: `03_03_구매자자기계산지급비용.md` → `구매자자기계산지급비용`
   - 파일명이 한글 붙임말인 경우 그대로 사용하되, 의미 단위로 띄어쓰기를 추가한다.
     - 예: `구매자자기계산지급비용` → `구매자 자기계산 지급 비용`
   - 자동 추출 결과가 불명확하면 `AskUserQuestion`으로 사용자에게 확인한다.
3. 파일 내 섹션 구조를 파악한다:
   - `## [1]`, `## [2]` ... `## [7]` 등 기존 헤딩 목록 확인
   - `## [부록]` 위치 확인 (이 이하는 절대 수정하지 않는다)

## STEP 3 — NotebookLM 질의

> ⚠ **반드시 PowerShell 도구를 사용한다.** Bash 도구는 한글 인코딩이 깨지므로 절대 사용하지 않는다.

**고정값**

**PowerShell 실행 형식**:
```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONUTF8 = "1"
```

**타임아웃 대응**:

**응답 후처리**:

  - **파트C**: `3. 세부 내용` 헤딩부터 끝까지 (표 포함)

## STEP 4 — 파일 수정 (Edit 도구만 사용, Write 금지)

> ⚠ **Write 도구로 전체 파일을 덮어쓰지 않는다.** 변경이 필요한 부분만 Edit 도구로 최소 수정한다.

### STEP 4-A: 기존 섹션 재번호 (역순으로 Edit)

기존 [3]~[7] 헤딩을 **역순**으로 Edit 도구를 사용해 헤딩 줄만 교체한다.
역순으로 처리해야 중복 헤딩 충돌이 발생하지 않는다.

| 순서 | old_string (헤딩 줄 전체) | new_string |
|------|--------------------------|------------|
| 1 | `## [7] ...제목...` | `## [8] ...제목...` |
| 2 | `## [6] ...제목...` | `## [7] ...제목...` |
| 3 | `## [5] ...제목...` | `## [6] ...제목...` |
| 4 | `## [4] ...제목...` | `## [5] ...제목...` |
| 5 | `## [3] ...제목...` | `## [4] ...제목...` |

- 파일에 [3]~[7] 이외의 번호가 있는 경우 실제 헤딩 목록을 기준으로 역순 +1한다.
- 헤딩 줄 한 줄만 교체하므로 섹션 내용은 변경되지 않는다.

### STEP 4-B: [1][2] 섹션 교체 + [3] 신규 삽입 (Edit 1회)

Edit 도구 1회 호출로 기존 `## [1]`~`## [2]` 블록 전체를 새 [1]+[2]+[3]으로 교체한다.

```
old_string:
  ## [1] {기존 헤딩 제목}
  {기존 [1] 섹션 전체 내용}
  ---
  ## [2] {기존 헤딩 제목}
  {기존 [2] 섹션 전체 내용}
  ---

new_string:
  ## [1] 근거 법령 조문
  {NLM 파트A 내용}
  ---
  ## [2] 핵심 요약
  {NLM 파트B 내용}
  ---
  ## [3] 세부 내용
  {NLM 파트C 내용}
  ---
```

- `## [부록]` 이하는 절대 건드리지 않는다.

아래 형식으로 결과를 출력한다:

```
✅ 재작성 완료: <파일명>
- 단원이름: <사용된 단원이름>

- 재번호 섹션: [3]→[4], [4]→[5], ..., [7]→[8]
- 보존 섹션: [부록] 관련 조문 원문
```

## 주의사항 요약

| 항목 | 규칙 |
|------|------|
| 인코딩 | PowerShell만 사용, Bash 금지 |
| 파일 수정 | Edit 도구만 사용, Write 도구로 전체 덮어쓰기 금지 |
| 재번호 순서 | 역순([7]→[8] 먼저)으로 Edit — 정순으로 하면 헤딩 중복 충돌 발생 |
| [부록] 보존 | `## [부록]` 이하는 절대 수정하지 않음 |
| 메타데이터 보존 | 파일 상단 테이블(출제티어, 핵심법령 등) 그대로 유지 |
| 타임아웃 | 실패 시 축약 프롬프트로 1회 재시도 |
| 단원이름 불명확 | AskUserQuestion으로 사용자 확인 후 진행 |
