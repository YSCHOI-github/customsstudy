# 단권화 대화형 퀴즈 스킬

단권화 MD 파일을 기반으로 대화형 퀴즈를 출제하고, 사용자 답변을 단권화 내용 및 관련 법령에 근거하여 평가한다.
퀴즈 결과는 과목별 `[과목]_quiz_results.md`에 축적하여 취약 영역을 분석할 수 있게 한다.

## 사용법

```
/단권화-quiz [과목] [파일경로1] [파일경로2] ... [--n 문항수] [--style 스타일]
```

- **과목**: `관세평가` 또는 `무역실무`
- **파일경로**: 단권화 MD 파일 경로 (1개 이상, 복수 가능)
- **--n**: 출제할 문항 수 (기본값: 10)
- **--style**: `객관식` / `단답형` / `서술형` (기본값: 단답형)

### 예시

```
/단권화-quiz 관세평가 01_관세평가/10_단권화/02_01_과세가격결정기본원칙.md 01_관세평가/10_단권화/02_02_평가방법의적용순위.md --n 10 --style 단답형
```

```
/단권화-quiz
```
→ 옵션 없이 호출 시 AI가 과목·파일·문항수·스타일을 순서대로 사용자에게 문의한다.

### STEP 0 — 옵션 파싱 및 인터랙티브 모드

옵션이 제공되지 않은 경우, 아래 순서로 사용자에게 문의한다.
옵션이 부분 제공된 경우 누락된 항목만 문의한다.

1. **과목 선택**: "퀴즈 과목을 선택해주세요: `관세평가` / `무역실무`"
2. **파일 선택**: 해당 과목 단권화 폴더의 파일 목록을 `list_dir` 도구로 조회하여 번호와 함께 표시한다. `*quiz_results.md` 파일과 `00_` 시작 파일(목차)은 제외한다. "퀴즈에 사용할 파일 번호를 선택해주세요 (여러 개는 쉼표로 구분)"
3. **문항 수**: "몇 문항을 출제할까요? (기본값: 10)"
4. **스타일 선택**: "문제 스타일을 선택해주세요: `객관식` / `단답형` / `서술형`"

모든 옵션이 확인되면 STEP 1로 진행한다.

### STEP 1 — 단권화 파일 읽기

지정된 모든 MD 파일을 `view_file` 도구로 **전체 내용**을 읽는다.

파일마다 목차 구조가 다르므로 특정 섹션명에 의존하지 않는다. 대신 아래 기준으로 내용을 파악한다:

- **시험 출제 핵심**: 별표(`★`) 표시가 있는 항목, 출제율·출제 티어 정보, 체크리스트·암기 키워드로 표시된 내용
- **이론 내용**: 개념 정의, 요건, 절차, 예외, 비교표, 판단 흐름도 등 본문 전체
- **계산 공식**: 수식·공식 블록, 계산 사례
- **기출 패턴**: 회차·연도별 출제 사례, 빈출 패턴 설명
- **법령 조문**: 관련 조문 원문(관세법·시행령·시행규칙 등) — 답변 평가 시 조문 근거로 활용

파일을 읽은 후, 퀴즈 출제에 활용할 핵심 주제 목록을 내부적으로 정리한다.

---

### STEP 2 — 문제 풀(Pool) 생성

파일 내용을 분석하여 지정 문항 수의 **1.5배** 분량의 문제 후보를 내부적으로 생성한다.

#### 스타일별 문제 형식

**객관식 (4지선다)**
```
Q. [문제]
① [선택지A]
② [선택지B]
③ [선택지C]
④ [선택지D]
```
오답 선택지는 단권화 내 유사 개념을 활용해 실질적 혼동을 유발하도록 구성한다.

**단답형**
```
Q. [법령 용어·요건·조문번호 등을 묻는 질문]
```
법령 정확 표현, 조문번호, 숫자 요건(예: 60일, 4가지 등)을 묻는다.

**서술형**
```
Q. [개념의 이유·차이·적용 흐름을 설명하게 하는 질문]
```

#### 출제 기준
- `★★★`·`★★` 표시 항목을 우선 출제한다.
- 동일 주제가 반복되지 않도록 분산한다.
- 기출 패턴([5] 기출 기반 사례 응용 섹션)을 참고한다.
- 난이도: 기본 개념 30% / 법령 요건 40% / 예외·심화 30%

---

### STEP 3 — 대화형 퀴즈 진행

아래 사이클을 문항 수만큼 반복한다.

#### 문제 출제 형식

```
## 📝 [과목] 퀴즈 (N/전체)

**Q[N].** [문제 내용]

[객관식인 경우 선택지 표시]
```

#### 답변 처리 규칙

- 사용자가 답변을 입력할 때까지 기다린다.
- `"모르겠어"` / `"패스"` / `"skip"` 입력 시: 정답을 공개하고 결과를 `✗ 미응답`으로 기록한다.
- 사용자가 틀린 내용을 주장하더라도 단권화 및 법령 원문에 근거해 정확히 평가한다.

#### 답변 평가 형식

```
## 📋 Q[N] 답안 평가

### 판정: [○ 정답 / △ 부분 정답 / ✗ 오답 / ✗ 미응답]

[평가 내용 — 단권화 및 법령 원문 근거 명시]

### 모범 답안
[법령 표현을 포함한 모범 답안]
[필요 시 표·비교·핵심 포인트 추가]
```

#### 판정 기준

| 판정 | 기준 |
|------|------|
| ○ 정답 | 핵심 내용 및 법령 표현 정확 |
| △ 부분 정답 | 방향은 맞으나 법령 표현·요건 일부 누락 |
| ✗ 오답 | 핵심 내용이 틀리거나 다른 개념과 혼동 |
| ✗ 미응답 | 모르겠다고 한 경우 |

#### 다음 문제 진행

사용자가 `"다음"` / `"다음 문제"` / `"ㅇㅋ"` / `"좋아"` / `"넘어가자"` 등을 입력하면 다음 문제로 진행한다.

---

### STEP 4 — 최종 성적표 출력

모든 문항이 끝나면 아래 형식으로 성적표를 출력한다.

```
## 🏁 퀴즈 종료! 최종 성적표

**과목**: [과목명]
**참조 파일**: [파일명 목록]
**문제 스타일**: [스타일]
**일시**: [YYYY-MM-DD]

| 번호 | 주제 | 판정 | 취약 포인트 |
|------|------|------|-----------|
| Q1   | ...  | ○    | —         |
| Q2   | ...  | △    | [누락 키워드] |
| Q3   | ...  | ✗    | [혼동한 개념] |

**점수**: [X.X] / [전체] (△은 0.5점)

### 📌 취약 영역 분석
- **반복 오답**: [오답 집중 주제]
- **부분 정답 패턴**: [자주 누락되는 법령 표현]
- **우선 복습 권장**: [파일명 및 섹션명]
```

### STEP 5 — 결과를 [과목]_quiz_results.md에 저장

과목별 `[과목]_quiz_results.md` 파일에 이번 퀴즈 결과를 **append**한다. 파일이 없으면 헤더를 포함하여 새로 생성한다.

#### 신규 파일 생성 시 헤더

```markdown
# [과목] 퀴즈 결과 누적 기록

이 파일은 `/단권화-quiz` 스킬이 자동으로 생성·관리합니다.
퀴즈를 반복 수행하면 결과가 아래에 누적되어 취약 영역을 파악할 수 있습니다.

---
```

#### 회차별 저장 형식

```markdown
## [YYYY-MM-DD HH:MM] | [과목] | [스타일] | [N]문항

**참조 파일**: [파일명1], [파일명2], ...

| 번호 | 주제 | 판정 | 취약 포인트 |
|------|------|------|-----------|
| Q1   | [주제] | ○  | —         |
| Q2   | [주제] | △  | [누락 키워드] |
| Q3   | [주제] | ✗  | [혼동 개념] |

**점수**: [X.X] / [N] | **취약 영역**: [주제1], [주제2], ...

---
```

저장 완료 후 사용자에게 알린다:
```
✅ 퀴즈 결과가 저장되었습니다: [[과목]_quiz_results.md 전체 경로]
```
