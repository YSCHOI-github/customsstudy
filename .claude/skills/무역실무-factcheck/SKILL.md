# 무역실무 단권화 팩트체크

무역실무 단권화 MD 파일을 NotebookLM 무역실무챗봇(대외무역법·외국환거래법·관세법·UCP 600·Incoterms 2020·CISG·헤이그-비스비 규칙·함부르크 규칙·로테르담 규칙·영국 MIA 1906·협회화물약관(ICC A/B/C)·뉴욕협약·무역보험법 원문 보유)과 대조하여 팩트체크하고, 오류와 보완사항을 자동 수정한 뒤 결과를 `_factcheck_report.md`에 기록한다.

## 사용법

```
/무역실무-factcheck <md_파일_경로>
```

예시:
```
/무역실무-factcheck 02_무역실무/10_단권화/03_02_신용장UCP600.md
```

---

## 실행 지시문

ARGUMENTS에 지정된 MD 파일 경로를 대상으로 아래 STEP을 순서대로 실행하라.
사용자 확인을 기다리지 말고 STEP 1~7을 끝까지 자동 실행하라.

**자동화 규칙 (이 스킬 내에서 아래 명령은 사용자 확인 없이 즉시 실행한다):**
- `notebooklm use` — 노트북 컨텍스트 설정
- `notebooklm ask` — 청크별 팩트체크 질의
- `notebooklm history --save` — 채팅 기록 노트 저장 (notebooklm 스킬의 기본 동작과 달리 이 스킬에서는 자동 실행)

---

### STEP 1 — 파일 읽기 및 청크 분할

1. `Read` 도구로 대상 MD 파일 전체를 읽는다.
2. `##`로 시작하는 섹션 헤더를 기준으로 청크를 나눈다.
3. 청크 크기를 조정한다:
   - 한 청크가 150줄을 초과하면 섹션을 나눠 두 청크로 분리한다.
   - 한 청크가 40줄 미만이면 인접 섹션과 합쳐 하나의 청크로 만든다.
4. 최종 청크 수는 파일 크기에 따라 조정한다:
   - 파일이 300줄 미만이면 3~4개, 300줄 이상이면 5~6개를 목표로 한다.

> ⚠️ 무역실무 파일은 최대 677줄에 달하므로 청크 수 상한(6개)을 유연하게 적용한다.

### STEP 3 — 청크별 팩트체크 질의

각 청크마다 아래 형식으로 `notebooklm ask`를 순차 실행한다.
**MD 파일 내용은 반드시 프롬프트 텍스트로 직접 삽입한다. `source add`로 추가하면 안 된다.**

```bash
CHUNK="[해당 청크의 실제 텍스트]"
PYTHONIOENCODING=utf-8 notebooklm ask "다음은 무역실무 단권화 학습자료입니다. 이 노트북에 있는 원문 자료(대외무역법·외국환거래법·관세법 등 한국 법령, UCP 600·Incoterms 2020·CISG·헤이그-비스비 규칙·함부르크 규칙·로테르담 규칙·영국 MIA 1906·협회화물약관(ICC A/B/C)·뉴욕협약·무역보험법 등 국제규범)를 기준으로, 아래 내용 중 원문과 다르거나 잘못된 내용을 구체적으로 지적해 주세요. 해당 내용과 관련된 조문·조항·규칙 번호를 함께 명시해 주세요. 틀린 내용이 없으면 '이상 없음'이라고 답해주세요.

$CHUNK"
```

각 청크의 결과를 변수 또는 메모에 저장해 둔다.

---

### STEP 4 — 결과 취합 및 분류

모든 청크의 응답을 합쳐 아래 두 범주로 분류한다:

- **🔴 오류**: 원문과 명확히 다른 내용 (조문번호 오류, 존재하지 않는 요건, 잘못된 당사자 등)
- **🟡 보완**: 표현이 불충분하거나 누락된 내용 (법령 용어 보완, 조건 추가, 조항 번호 누락 등)

이상 없는 섹션도 목록으로 기록해 둔다.

---

### STEP 5 — 자동 수정 적용

`Edit` 도구를 사용해 대상 MD 파일에 수정을 적용한다.

규칙:
- 🔴와 🟡 모두 수정한다.
- 기존 포맷(헤더 레벨, 표, 코드블록, 들여쓰기)을 유지한다.
- 조문번호·요건·표현 등 내용만 최소한으로 변경한다.
- 섹션 추가·삭제·재구성은 하지 않는다.

---

### STEP 6 — NotebookLM 채팅 기록 저장

팩트체크에 사용한 대화 기록을 NotebookLM 노트로 저장한다. **사용자 확인 없이 즉시 실행한다.**

```bash
PYTHONIOENCODING=utf-8 notebooklm history --save --note-title "무역실무 팩트체크 | <파일명> | <YYYY-MM-DD>"
```

- `<파일명>`은 대상 MD 파일의 basename(확장자 제외)으로 치환한다.
- `<YYYY-MM-DD>`는 오늘 날짜로 치환한다.
- 저장 성공 시 계속 진행하고, 실패 시 경고만 출력하고 STEP 7을 계속 진행한다.

---

### STEP 7 — 결과를 _factcheck_report.md에 기록

대상 MD 파일과 **같은 폴더**에 `_factcheck_report.md`가 있으면 파일 끝에 append하고, 없으면 새로 생성한다.

아래 형식으로 기록한다:

```markdown
## <YYYY-MM-DD> | <파일명>

### 🔴 수정됨 (<N>건)
- [항목 설명]: `[변경 전]` → `[변경 후]` (근거: [조문·조항·규칙 번호])

### 🟡 수정됨 (<N>건)
- [항목 설명]: [변경 내용] (근거: [조문·조항·규칙 번호])

### ✅ 이상 없음
- [이상 없는 섹션 목록]

---
```

수정 사항이 없는 범주는 해당 헤더를 생략한다.
모든 작업이 끝나면 `_factcheck_report.md` 기록 완료 및 NotebookLM 노트 저장 여부를 한 줄로 사용자에게 알린다.
