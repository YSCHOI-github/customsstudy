# 관세평가 단권화 핵심요약 생성기

관세평가 단권화 MD 파일의 본문 내용을 분석하여 `## 2. 핵심 요약` 섹션을 새로 작성하거나 기존 섹션을 덮어쓴다.

## 사용법

```
/핵심요약관세평가 <파일명_또는_경로>
```

예시:
```
/핵심요약관세평가 03_01_제1방법적용과수출판매
/핵심요약관세평가 01_관세평가/10_단권화/05_09_운임보험료.md
```

파일명은 전체 경로 없이 일부만 입력해도 된다. `01_관세평가/10_단권화/` 폴더에서 자동으로 매칭한다.

---

## 실행 지시문

ARGUMENTS에 지정된 파일명을 대상으로 아래 STEP을 순서대로 실행하라.  
사용자 확인을 기다리지 말고 STEP 1~4를 끝까지 자동 실행하라.

---

### STEP 1 — 대상 파일 확정

1. ARGUMENTS에서 파일명 또는 경로 문자열을 추출한다.
2. 전체 경로가 아닌 경우: `Glob` 도구로 `01_관세평가/10_단권화/**/*.md` 패턴을 검색하여 ARGUMENTS 문자열을 포함하는 파일을 찾는다.
3. 매칭 결과가 2개 이상이면 목록을 출력하고 사용자에게 선택을 요청한 뒤 대기한다.
4. 매칭 결과가 0개이면 오류 메시지를 출력하고 종료한다.
5. `Read` 도구로 대상 파일 전체를 읽는다.

---

### STEP 1.5 — 출제 트렌드 가이드 교차 참조

`Read` 도구로 아래 파일을 읽어, 대상 파일의 논점이 시험 출제 맥락에서 어느 위치인지 파악한다.

```
01_관세평가/20_기출문제_원문_트렌드분석/관세평가_종합합격가이드_4인전문가통합.md
```

이 파일에서 **아래 항목만** 확인한다 (전체 내용 분석 불필요):

| 확인 항목 | 가이드 내 위치 | 활용 목적 |
|---|---|---|
| **핵심 빈출 테마 TOP 7** | §2-2 | 대상 파일의 논점이 최상위 빈출인지 확인 → 강조 수위 결정 |
| **배점 비중 데이터** | §2-1 | 해당 평가방법·영역의 전체 배점 비중 파악 |
| **함정 TOP 10** | §6-1 | 대상 논점과 관련된 감점 함정 → 핵심요약 내 경고 표시 |
| **최근 출제 트렌드** | §5-1 | 최근 사례판단형 확대·개정법령 반영 여부 |

> **주의**: 가이드 내용을 핵심요약에 직접 복사하여 추가하지 않는다.  
> 가이드는 **강조 수위 조정**(빨간색·★ 표시)과 **함정 경고 문구 삽입** 용도로만 활용한다.  
> 핵심요약에 기재하는 내용은 반드시 **대상 파일 본문에 존재하는 내용**이어야 한다.

---

### STEP 2 — 본문 분석

읽은 파일에서 아래 정보를 추출한다.

#### A. 파일 구조 파악

- 파일 상단 메타 테이블(출제 티어, 출제율, 핵심 법령, 연계 절)을 확인하여 이 파일의 중요도와 분량 규모를 파악한다.
- 핵심 요약 섹션이 존재하는지 확인한다.
  - `## 2. 핵심 요약` 또는 `## [2] 핵심 요약` 형태를 탐색한다.
  - **존재하면**: 해당 섹션의 헤더 라인부터 바로 다음 `## ` 수준 섹션 헤더 직전 라인까지를 **교체 대상 블록**으로 기록한다.
  - **없으면**: `## 1. 근거 법령 조문` 또는 `## [1] 근거 법령 조문` 섹션의 마지막 `---` 구분선 직후를 **삽입 위치**로 기록한다.
- 본문 섹션 목록(`## 3.`, `## [3]`, `## 4.` 등)을 파악한다.
- 파일 전체 본문 분량(대략적인 줄 수)을 파악하여 핵심요약 적정 분량의 기준으로 삼는다.

#### B. 핵심 내용 추출

본문에서 아래 항목을 추출한다.

1. **조문별 핵심 요건·효과·절차**: `관세법 제XX조`, `시행령 제XX조`, `시행규칙 제XX조`, `고시 제XX조` 등 조문과 연결된 핵심 내용
2. **법정 열거 항목**: ①②③ 또는 1호·2호·3호로 나열된 항목 — 키워드만 추출
3. **판단 기준 및 처리 분기**: 가산/불가산, 포함/배제, 적용 가능/불가, 우선순위 등 판단 구조
4. **기존 암기법**: 파일 본문에 이미 존재하는 암기 문자열 — 원문 그대로 보존
5. **기출 포인트**: `★` 또는 `기출`로 표시된 항목 — 핵심요약에 반드시 포함
6. **비교·대조 개념쌍**: `vs`, `비교` 등으로 표시된 대비 항목 — 양쪽 키워드 모두 추출

#### C. 출제 트렌드 교차 강조 조정

STEP 1.5에서 확인한 가이드 정보를 바탕으로, 아래 기준에 따라 강조 수위를 결정한다.

- **가이드 §2-2 빈출 테마 TOP 7에 해당하는 논점** → 해당 항목에 `<font color="#ff0000">빨간색</font>` 적용 + 필요 시 소제목 앞에 ★ 추가
- **가이드 §6-1 함정 TOP 10에 해당하는 항목** → 해당 항목 말미에 `⚠` 또는 `<font color="#ff0000">감점 주의</font>` 표시 삽입
- **가이드 §5-1에서 최근 사례판단형으로 전환된 논점** → 소제목에 `(사례판단형)` 부기
- **가이드 §2-1 배점 비중이 낮은 영역**(제2·3·5방법 등) → 핵심요약 분량을 최소화하여 비중 반영

---

### STEP 3 — 핵심요약 작성

아래 **서식 규칙**을 반드시 준수하여 핵심 요약 블록을 작성한다.

#### 서식 규칙

1. **섹션 헤더**:
   - 기존 핵심 요약이 있으면 기존 헤더 형식(`## 2. 핵심 요약` 또는 `## [2] 핵심 요약`)을 그대로 유지한다.
   - 새로 삽입하는 경우 `## 2. 핵심 요약`을 사용한다.
2. **넘버링 금지**: 소항목에 `2.1.`, `2.2.` 같은 번호를 붙이지 않는다.
3. **블릿 구조**: `*` 블릿 + 탭 인덴트로 계층화한다.
   - 최상위: `* **[소제목/개념]** ([[#조문명|조문 표기]]):`
   - 하위: `	* 핵심 키워드 / 판단 기준`
   - 세부: `		* 세부 항목`
   - **표(table) 사용 절대 금지** — 비교 항목도 블릿·인덴트로 표현
4. **조문 링크**: `[[#관세법 제30조|관세법 제30조]]제1항` 형식으로 조문 번호와 항·호까지 명시한다.
5. **강조 서식**:
   - 핵심 키워드: `**굵게**`
   - 암기 필수·감점 위험 항목: `<font color="#ff0000">빨간색</font>`
6. **암기법**: 파일 본문에 이미 존재하는 것만 그대로 사용. **새 암기법 생성 금지**
7. **분량**: 파일 전체 본문 분량에 비례하여 유연하게 결정한다.
   - 본문이 짧은 파일(~50줄): 핵심요약 10~20줄
   - 본문이 중간인 파일(~150줄): 핵심요약 20~35줄
   - 본문이 긴 파일(150줄~): 핵심요약 35~60줄
   - 어느 경우든 장황한 설명문은 금지 — 키워드·조문 구조만
8. **금지 항목**:
   - 넘버링 소항목 (`2.1.`, `2.2.` 등)
   - 표(table)
   - 본문에 없는 내용 추가 (가이드 내용을 직접 복사하는 것 포함)
   - 장황한 설명문
   - 가이드에만 있고 대상 파일 본문에 없는 기출연도·통계·수치 삽입

#### 소제목 구성 기준

- 본문의 주요 섹션(`## 3.1`, `## 3.2` 등) 또는 핵심 논점(요건·효과·절차·예외) 단위로 소제목 구성
- 내용이 적은 논점은 인접 논점과 묶는다.
- 소제목 수 상한: 파일 분량에 따라 5~9개

#### 작성 예시 (참고용)

```markdown
## 2. 핵심 요약

* **[수출판매 요건]** ([[#관세법 제30조|관세법 제30조]]제1항, [[#고시 제15조|고시 제15조]]제1항)
	* **자기 책임과 계산** + **대가 지급** + **소유권 이전** — 세 요건 모두 충족해야 유효한 판매
	* 실제적인 **국제 간 이동** 수반 필수
	* 연속판매 시 → **우리나라 도착 직전 마지막 판매** 가격 적용

* **[수출판매 제외 7대 사유]** ([[#시행령 제17조|시행령 제17조]])
	* 무상반입 / 위탁판매 / 수출자 국내판매 / 본·지점 거래
	* 임대차 / 무상임차 / 수출자 국내폐기
	* → 소유권 이전 또는 대가 지급 요건 미충족 → <font color="#ff0000">**제1방법 전면 배제**</font>

* **[제1방법 배제사유 총람]** ([[#고시 제14조|고시 제14조]])
	* ① 수출판매가 아닌 경우
	* ② 수출판매임을 확인할 수 없는 경우
	* ③ 실제지급가격 확인 불가
	* ④ 법정 가산요소 객관화·수량화 불가
	* ⑤ 법정 배제요건 해당 (처분제한·조건사정·사후귀속이익·특수관계)
	* ⑥ 자료제출 요구에 소명 불가

---
```

### STEP 4 — 파일 쓰기 및 결과 보고

1. **기존 핵심요약 있는 경우**: `Edit` 도구를 사용하여 기존 핵심 요약 헤더 라인부터 다음 `## ` 수준 섹션 헤더 직전 라인까지를 새로 작성한 내용으로 교체한다.
2. **기존 핵심요약 없는 경우**: 근거 법령 조문 섹션(`## 1.` 또는 `## [1]`) 끝의 `---` 구분선 직후에 핵심요약 블록을 삽입하고 블록 끝에 `---` + 빈 줄을 추가한다.
3. 작업 완료 후 한 줄로 결과를 보고한다:
   ```
   ✅ [파일명] 핵심요약 [생성|업데이트] 완료
   ```
