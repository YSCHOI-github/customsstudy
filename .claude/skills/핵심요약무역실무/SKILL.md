# 무역실무 단권화 핵심요약 생성기

무역실무 단권화 MD 파일의 본문 내용을 분석하여 `## 📝 핵심 요약` 섹션을 새로 작성하거나 기존 섹션을 덮어쓴다.

## 사용법

```
/핵심요약무역실무 <파일명_또는_경로>
```

예시:
```
/핵심요약무역실무 01_01_CISG_계약성립
/핵심요약무역실무 02_무역실무/10_단권화/01_02_CISG_이행법리.md
```

파일명은 전체 경로 없이 일부만 입력해도 된다. `02_무역실무/10_단권화/` 폴더에서 자동으로 매칭한다.

---

## 실행 지시문

ARGUMENTS에 지정된 파일명을 대상으로 아래 STEP을 순서대로 실행하라.  
사용자 확인을 기다리지 말고 STEP 1~4를 끝까지 자동 실행하라.

---

### STEP 1 — 대상 파일 확정

1. ARGUMENTS에서 파일명 또는 경로 문자열을 추출한다.
2. 전체 경로가 아닌 경우: `Glob` 도구로 `02_무역실무/10_단권화/**/*.md` 패턴을 검색하여 ARGUMENTS 문자열을 포함하는 파일을 찾는다.
3. 매칭 결과가 2개 이상이면 목록을 출력하고 사용자에게 선택을 요청한 뒤 대기한다.
4. 매칭 결과가 0개이면 오류 메시지를 출력하고 종료한다.
5. `Read` 도구로 대상 파일 전체를 읽는다.

---

### STEP 2 — 본문 분석

읽은 파일에서 아래 정보를 추출한다.

#### A. 파일 구조 파악

- `## 📝 핵심 요약` 섹션이 존재하는지 확인한다.
  - 존재하면: 해당 섹션의 시작 라인(헤더 포함)부터 바로 다음 `---` 구분선 직전까지를 **교체 대상 블록**으로 기록한다.
  - 없으면: 파일 상단 front matter 끝의 `---` 구분선 직후를 **삽입 위치**로 기록한다.
- `## §` 또는 `## 1.`, `## 2.` 등으로 시작하는 본문 섹션 목록을 파악한다.

#### B. 핵심 내용 추출

본문 각 섹션에서 아래 항목을 추출한다.

1. **조문별 핵심 요건**: `CISG 제XX조`, `UCP 600 제XX조`, `Incoterms 2020 AX/BX` 등 조문 번호와 그에 연결된 핵심 요건·효과·예외
2. **열거 항목**: 번호 목록(①②③ 또는 1.2.3.)으로 나열된 항목 — 키워드만 조문 순서대로 추출
3. **기존 암기법**: 파일 본문에 이미 존재하는 `**X·X·X**` 형태의 암기법 문자열 — 원문 그대로 보존
4. **기출 포인트**: `★` 또는 `기출`로 표시된 항목 — 핵심요약에 반드시 포함
5. **비교 개념쌍**: `vs`, `비교` 등으로 표시된 대비 항목 — 양쪽 키워드 모두 추출

---

### STEP 3 — 핵심요약 작성

아래 **서식 규칙**을 반드시 준수하여 `## 📝 핵심 요약` 블록을 작성한다.

#### 서식 규칙

1. **섹션 헤더**: `## 📝 핵심 요약` 고정 (변경 불가)
2. **소제목**: `##### **N. 소제목**` 형식 (N은 1부터 순서대로)
3. **블릿 구조**: `-` 블릿 + 탭 인덴트로 계층화
   - **표(table) 사용 절대 금지** — 비교 항목도 블릿·인덴트로 표현
4. **조문 링크**: `[[#조문섹션명|CISG 제XX조]]` 형식으로 본문 앵커 링크 포함
   - 링크 형식 예시: `([[#CISG Article 14|CISG 제14조]])`
5. **강조 서식**:
   - 핵심 키워드: `**굵게**`
   - 암기 필수·감점 위험 항목: `<font color="#ff0000">빨간색</font>`
6. **암기법**: 파일 본문에 이미 존재하는 것만 그대로 사용. **새 암기법 생성 금지**
7. **키워드 열거**: 새로 추가하는 암기 항목은 암기법 없이 키워드를 조문 순서대로 나열
8. **분량**: 핵심요약 전체 30~50줄 이내로 간결하게 작성
9. **금지 항목**:
   - 빈출 함정(⚠️) 별도 섹션 금지
   - 표(table) 금지
   - 본문에 없는 내용 추가 금지
   - 장황한 설명문 금지 — 키워드·조문 구조만

#### 소제목 구성 기준

- 본문의 주요 섹션(`## §1`, `## 1.` 등) 하나당 소제목 하나를 원칙으로 한다.
- 내용이 10줄 미만인 섹션은 인접 섹션과 묶어 하나의 소제목으로 처리한다.
- 소제목 수 상한: 7개

#### 작성 예시 (참고용)

```markdown
## 📝 핵심 요약

##### **1. 소제목**
- **핵심개념** ([[#CISG Article 14|CISG 제14조]]): 키워드1 / 키워드2 / 키워드3
	- 세부항목 ①: 내용
	- 세부항목 ②: 내용
- **비교개념** ([[#CISG Article 19|CISG 제19조]]): A → 결과A / B → 결과B

##### **2. 소제목**
- **기존암기법 항목** ([[#CISG Article 2|CISG 제2조]]): <font color="#ff0000">**경·강·소·주·선·전**</font> (경매, 강제집행, ...)
- **열거 항목** ([[#CISG Article 33|CISG 제33조]])
	- 기일 고정 → 해당 기일
	- 기간 고정 → 그 기간 내 (선택권: 매도인)
	- 기일·기간 없음 → **합리적 기간(Reasonable Time)**

---
```

---

### STEP 4 — 파일 쓰기 및 결과 보고

1. **기존 핵심요약 있는 경우**: `Edit` 도구를 사용하여 `## 📝 핵심 요약` 헤더부터 바로 다음 `---` 구분선(포함) 직전 라인까지를 새로 작성한 내용 + `---`으로 교체한다.
2. **기존 핵심요약 없는 경우**: 파일 첫 번째 `---` 구분선(front matter 끝) 직후에 핵심요약 블록 + `---` + 빈 줄을 삽입한다.
3. 작업 완료 후 한 줄로 결과를 보고한다:
   ```
   ✅ [파일명] 핵심요약 [생성|업데이트] 완료 (N개 섹션)
   ```
