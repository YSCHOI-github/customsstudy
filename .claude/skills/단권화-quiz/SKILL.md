# 단권화 대화형 퀴즈 스킬

단권화 MD 파일을 기반으로 대화형 퀴즈를 출제하고, 사용자 답변을 단권화 내용 및 관련 법령에 근거하여 평가한다.
퀴즈 결과는 과목별 `[과목]_quiz_results.md`에 축적하여 취약 영역을 분석할 수 있게 한다.

## 사용법

```
/단권화-quiz [--mode 단권화|기출] [과목] [파일경로 또는 연도] [--n 문항수] [--style 스타일]
```

- **--mode**: `단권화` (기본값) / `기출`
- **과목**: `관세평가` 또는 `무역실무`
- **단권화 모드 전용**
  - **파일경로**: 단권화 MD 파일 경로 (1개 이상, 복수 가능)
  - **--n**: 출제할 문항 수 (기본값: 10)
  - **--style**: `객관식` / `단답형` / `서술형` / `혼합` (기본값: 단답형)
    - `혼합`: 기본 개념→객관식, 법령 요건→단답형, 예외·심화→서술형으로 자동 배분
- **기출 모드 전용**
  - **연도**: 4자리 연도 (예: `2024`)

### 예시

```
/단권화-quiz 관세평가 01_관세평가/10_단권화/02_01_과세가격결정기본원칙.md --n 10 --style 단답형
```

```
/단권화-quiz --mode 기출 관세평가 2024
```

```
/단권화-quiz --mode 기출
```
→ 기출 모드 무옵션 호출 시 AI가 과목·연도를 순서대로 문의한다.

```
/단권화-quiz
```
→ 옵션 없이 호출 시 AI가 모드·과목 등을 순서대로 문의한다.

### STEP 0 — 옵션 파싱 및 인터랙티브 모드

**먼저 `--mode` 옵션을 확인한다.**
- `--mode 기출` 감지 시: 아래 단권화 모드 질문을 건너뛰고 **STEP G0으로 이동**한다.
- `--mode 단권화` 또는 `--mode` 미지정 시: 아래 단권화 모드를 진행한다.
- `--mode` 미지정 + 다른 옵션도 없는 경우: "모드를 선택해주세요: `단권화` / `기출`"를 먼저 문의한다.

**단권화 모드 진행:**

옵션이 제공되지 않은 경우, 아래 순서로 사용자에게 문의한다.
옵션이 부분 제공된 경우 누락된 항목만 문의한다.

1. **과목 선택**: "퀴즈 과목을 선택해주세요: `관세평가` / `무역실무`"
2. **파일 선택**: 해당 과목 단권화 폴더를 `Glob` 도구로 `*.md` 패턴 조회하여 번호와 함께 표시한다. `*quiz_results.md`, `_factcheck_report.md`, `00_` 시작 파일(목차)은 제외한다. "퀴즈에 사용할 파일 번호를 선택해주세요 (여러 개는 쉼표로 구분)"
3. **문항 수**: "몇 문항을 출제할까요? (기본값: 10)"
4. **스타일 선택**: "문제 스타일을 선택해주세요: `객관식` / `단답형` / `서술형` / `혼합`"

모든 옵션이 확인되면 STEP 1로 진행한다.

### STEP 1 — 단권화 파일 읽기

지정된 모든 MD 파일을 `Read` 도구로 **전체 내용**을 읽는다.

파일마다 목차 구조가 다르므로 특정 섹션명에 의존하지 않는다. 대신 아래 기준으로 내용을 파악한다:

- **시험 출제 핵심**: 별표(`★`) 표시가 있는 항목, 출제율·출제 티어 정보, 체크리스트·암기 키워드로 표시된 내용
- **이론 내용**: 개념 정의, 요건, 절차, 예외, 비교표, 판단 흐름도 등 본문 전체
- **계산 공식**: 수식·공식 블록, 계산 사례
- **기출 패턴**: 회차·연도별 출제 사례, 빈출 패턴 설명
- **법령 조문**: 관련 조문 원문(관세법·시행령·시행규칙 등) — 답변 평가 시 조문 근거로 활용

복수 파일을 읽은 경우 파일 간 중복 주제는 병합하여 단일 풀 항목으로 처리한다.
파일을 읽은 후, 퀴즈 출제에 활용할 핵심 주제 목록을 내부적으로 정리한다.

### STEP 2 — 문제 풀(Pool) 생성

파일 내용을 분석하여 지정 문항 수의 **1.5배** 분량의 문제 후보를 내부적으로 생성한다.

#### 스타일별 문제 형식

**객관식 (4지선다)**
```
Q. [문제]
① [선택지A]
② [선택지B]
③ [선택지C]
④ [선택지D]
```
오답 선택지는 단권화 내 유사 개념을 활용해 실질적 혼동을 유발하도록 구성한다.

**단답형**
```
Q. [법령 용어·요건·조문번호 등을 묻는 질문]
```
법령 정확 표현, 조문번호, 숫자 요건(예: 60일, 4가지 등)을 묻는다.

**서술형**
```
Q. [개념의 이유·차이·적용 흐름을 설명하게 하는 질문]
```

**혼합 (자동 배분)**
- 기본 개념(30%) → 객관식
- 법령 요건(40%) → 단답형
- 예외·심화(30%) → 서술형

#### 출제 기준
- `★★★`·`★★` 표시 항목을 우선 출제한다.
- 동일 주제가 반복되지 않도록 분산한다.
- 기출 패턴([5] 기출 기반 사례 응용 섹션)을 참고한다.
- 난이도: 기본 개념 30% / 법령 요건 40% / 예외·심화 30%

### STEP 3 — 대화형 퀴즈 진행

아래 사이클을 문항 수만큼 반복한다.

#### 문제 출제 형식

```
## 📝 [과목] 퀴즈 (N/전체)

**Q[N].** [문제 내용]

[객관식인 경우 선택지 표시]
```

#### 답변 처리 규칙

- 사용자가 답변을 입력할 때까지 기다린다.
- `"모르겠어"` / `"패스"` / `"skip"` 입력 시: 정답을 공개하고 결과를 `✗ 미응답`으로 기록한다.
- `"그만"` / `"종료"` / `"exit"` / `"quit"` 입력 시: 즉시 STEP 4(성적표 출력)와 STEP 5(결과 저장)를 실행하고 종료한다.
- 사용자가 틀린 내용을 주장하더라도 단권화 및 법령 원문에 근거해 정확히 평가한다.

#### 답변 평가 형식

```
## 📋 Q[N] 답안 평가

### 판정: [○ 정답 / △ 부분 정답 / ✗ 오답 / ✗ 미응답]

[평가 내용 — 단권화 및 법령 원문 근거 명시]

### 모범 답안
[법령 표현을 포함한 모범 답안]
[필요 시 표·비교·핵심 포인트 추가]
```

#### 판정 기준

| 판정 | 기준 |
|------|------|
| ○ 정답 | 핵심 내용 및 법령 표현 정확 |
| △ 부분 정답 | 방향은 맞으나 법령 표현·요건 일부 누락 |
| ✗ 오답 | 핵심 내용이 틀리거나 다른 개념과 혼동 |
| ✗ 미응답 | 모르겠다고 한 경우 |

**서술형 채점 세부 기준:**

| 항목 | ○ 정답 | △ 부분 정답 | ✗ 오답 |
|------|--------|------------|--------|
| 논리 구조 | 요건·절차 체계적 서술 | 순서 오류·항목 누락 | 방향 자체가 틀림 |
| 법령 표현 | 조문 번호·용어 정확 | 내용은 맞으나 표현 부정확 | 무관한 조문 인용 |
| 예외·한계 | 명시적 언급 | 암묵적 포함 | 미언급 |

#### 답변 평가 하단 고정 안내

답변 평가 블록 맨 끝에 항상 아래 안내를 추가한다:

> 💬 이 문제에 대해 더 공부하고 싶은 내용이 있으면 질문해주세요.
> 다음 문제로 넘어가려면 **"다음"** 을 입력해주세요.

#### 다음 문제 진행 vs 학습 질문 분기

- 사용자 입력이 `"다음"` / `"다음 문제"` / `"ㅇㅋ"` / `"좋아"` / `"넘어가자"` / `"계속"` / `"ok"` / `"알겠어"` / `"이해했어"` / `"넘어가"` 중 하나이면 → 다음 문제로 진행한다.
- 그 외 모든 입력(질문·반박·보충 요청 등)은 **현재 문제의 학습 질문**으로 처리한다.
  - 단권화 내용 및 법령 원문을 근거로 답변한다.
  - 답변 후 위의 고정 안내를 다시 출력하고, 사용자 입력을 기다린다.
  - 다음 문제로 진행하지 않는다.

```markdown

]
```

- 배점은 기출문제 원문에서 추출한다. 명시되지 않은 경우 모범답안에서 역산한다.
- 전체 문항의 배점 합계를 확인한다 (보통 100점).

---

### STEP G3 — 물음 단위 순차 퀴즈

물음(소문항) 단위로 아래 사이클을 반복한다.

#### 문제 출제 형식

문제(대문항)가 바뀔 때는 거래내용·전제 조건 등 문제 지문 전체를 먼저 제시한다.

```
## 📝 [과목] [연도] 기출문제

### 문제 [N] ([총배점]점)

[문제 지문 — 거래내용, 전제 조건 등 전체 제시]

---

**물음 [M])** ([배점]점)

[물음 내용]
```

#### ⚠️ 출제 시 절대 금지 사항

- **힌트 절대 금지**: 물음을 출제할 때 어떠한 힌트, 참고사항, 보충 설명, 관련 조문 예시도 제공하지 않는다. 문제 지문과 물음 텍스트만 원문 그대로 출력한다.
- **원문 그대로 출제**: 기출문제 원문 파일에서 해당 물음 텍스트를 수정·요약·재구성하지 않고 그대로 출력한다. "※ 참고:", "힌트:", "관련 조문:" 등 어떤 형태의 추가 안내도 붙이지 않는다.

#### 답변 처리 규칙

- 사용자가 답변을 입력할 때까지 기다린다.
- `"모르겠어"` / `"패스"` / `"skip"` 입력 시: 모범답안 핵심을 공개하고 ✗ 미응답으로 기록한다.
- `"그만"` / `"종료"` / `"exit"` / `"quit"` 입력 시: 즉시 STEP G4·G5를 실행하고 종료한다.
- 사용자가 틀린 내용을 주장하더라도 모범답안 및 법령 원문에 근거해 정확히 평가한다.

#### 답변 평가 형식

```
## 📋 문제 [N] - 물음 [M] 답안 평가

### 판정: [○ / △ / ✗ / ✗미응답] | 획득: [X] / [배점]점

[모범답안 핵심 키포인트와 대조한 평가]

### 모범답안 핵심
[모범답안에서 추출한 핵심 내용 — 법령 표현 포함]
```

#### 판정 기준 (기출 모드)

| 판정 | 획득 점수 | 기준 |
|------|---------|------|
| ○ 정답 | 배점 100% | 핵심 요건·법령 표현 모두 충족 |
| △ 부분 정답 | 배점 50% | 방향은 맞으나 요건·표현 일부 누락 |
| ✗ 오답 | 0점 | 핵심 내용 오류 또는 다른 개념 혼동 |
| ✗ 미응답 | 0점 | 패스한 경우 |

#### 답변 평가 하단 고정 안내

답변 평가 블록 맨 끝에 항상 아래 안내를 추가한다:

> 💬 이 문제에 대해 더 공부하고 싶은 내용이 있으면 질문해주세요.
> 다음 물음으로 넘어가려면 **"다음"** 을 입력해주세요.

#### 다음 물음 진행 vs 학습 질문 분기

- 사용자 입력이 `"다음"` / `"다음 문제"` / `"ㅇㅋ"` / `"좋아"` / `"계속"` / `"ok"` / `"알겠어"` / `"넘어가"` 중 하나이면 → 다음 물음으로 진행한다.
- 그 외 모든 입력(질문·반박·보충 요청 등)은 **현재 물음의 학습 질문**으로 처리한다.
  - 모범답안 및 법령 원문을 근거로 답변한다.
  - 답변 후 위의 고정 안내를 다시 출력하고, 사용자 입력을 기다린다.
  - 다음 물음으로 진행하지 않는다.

---
